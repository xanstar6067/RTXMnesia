# RTXMnesia — личный порт Amnesia: The Dark Descent на Unity (HDRP, позже RTX)

Проект строго личный, не распространяется. Общаться с пользователем по-русски.

Этот файл — только правила и указатель. Подробные описания подсистем лежат в `docs/Reference/` (читать по требованию, перед работой над соответствующим кодом).

## Структура репозитория

| Путь | Что это | В git? |
|---|---|---|

| `docs/Reference/` | Справочник по подсистемам (индекс ниже) | да |
| `E:\SteamLibrary\steamapps\common\Amnesia The Dark Descent` | Установленная лицензионная игра (оригинал, не трогать) | — |

Правило авторского права: ресурсы Amnesia (текстуры, модели, звуки, карты, скрипты) **никогда не коммитятся**.
Любой импортированный в Unity контент должен лежать в игнорируемой папке (напр. `UnityProj/UMnesiaRTX/Assets/AmnesiaImported/` — добавить в `.gitignore` ДО первого импорта) и генерироваться
скриптами-конвертерами из `source/`. В git живёт только наш код: конвертеры, игровая логика, шейдеры, настройки HDRP.
Результаты ИИ-апскейла текстур — тоже ресурсы Amnesia, значит тоже вне git.

## Решения пользователя

- Языки: **русский** (основной, есть русская озвучка `lang/rus`) + **английский** как запасной. Остальные языки не импортируем.
- Объём: вся игра (глава 1 → 3, дополнение Justine). Скрипты уровней портируются **вручную на C#** (без AngelScript), каждая карта документируется в `docs/ScriptPort/` по шаблону README; код оригинала туда не копируется, только ссылки `файл:строка`. После переноса функции API обновлять её статус в `docs/ScriptPort/api.md`.
- Этапы 1–6.5 (импортёры, уровни, игрок, скрипты всех карт, звук, враги, меню, сохранения, профили, сложный режим) сделаны; идёт этап 7 — RTX в стиле «ремастер» (физически корректный свет, RTGI по умолчанию, DLSS, RT-тени/AO/отражения, path tracing; генерация кадров — Smooth Motion драйвера); этап 8 — улучшенные PBR-текстуры — сделан. Полный план с датами: `docs/Reference/Plan.md`.
- Исходники HPL2 (`src/`) — спецификация поведения: порт идёт по ним, числа берутся из `game.cfg`/`.ent` через `HplConfig`, не вписываются в код. Ошибки оригинала сохраняются, отступления фиксируются в документации.

## Соглашения

- Все автоматические проверки и фоновые тестовые запуски игры выполнять с громкостью 0% (решение пользователя 2026-10-24). Отключать только слышимый вывод тестового процесса, сохраняя логику звука и тайминги; обычную громкость игры и сохранённые настройки пользователя не менять. Если проверяется сама регулировка громкости, обеспечить тишину на уровне вывода тестового процесса.
- Релизные сборки (решение пользователя 2026-10-25) не создавать и не копировать: релиз пользователь собирает сам во внешнюю папку, от агента нужен только код. Проверки, которым нужен плеер, — только по прямой просьбе; такие тестовые сборки после проверки удалять.
- Лишние снимки в `UnityProj/UMnesiaRTX/Logs` (решение пользователя 2026-10-25): после проверки удалять PNG, которые больше не нужны (промежуточные, повторные, старых прогонов), оставлять только то, что показано пользователю или упомянуто в документации как итог; для экономии места.
- Код на C#:
  - `UnityProj/UMnesiaRTX/Assets/Scripts/`:
    - `Hpl/` — конвертации HPL→Unity, конфиг, язык, физ. запросы, `HplMath`;
    - `World/` — компоненты уровня;
    - `Dynamics/` — физика тел и джоинтов;
    - `Props/` — пропы;
    - `Sound/` — звук и музыка;
    - `Particles/` — системы частиц;
    - `Player/` — игрок;
    - `ScriptApi/` — карта и API скриптов;
    - `Effects/` — эффекты экрана;
    - `Save/` — сохранения;
    - `Ui/` — HUD, главное меню / пауза, настройки, инвентарь, журнал;
    - `Levels/ChXX/` — порты скриптов уровней;
    - `Dev/` — отладка;
  - `Assets/Shaders/` — наши шейдеры;
  - `Assets/Editor/` — конвертеры; редакторные проверки — `Assets/Editor/Dev`.
- Импортёры — Editor-скрипты, запускаемые также через `-executeMethod`.
- Числа из XML HPL парсить только с `CultureInfo.InvariantCulture` (`HplXml`): в русской локали разделитель — запятая.
- Не изменять ничего в папке установленной игры и в `src/`.
- Перед первым импортом ресурсов: убедиться, что `.gitignore` исключает импортированные папки (`git status` не должен показывать контент Amnesia).
- Оси: HPL `(x,y,z)` → Unity `(−x,y,z)`, повороты — отражением (X сохраняется, Y и Z меняют знак); всё это в `Assets/Scripts/Hpl/HplSpace.cs`. Логику с углами писать в пространстве HPL (`Hpl*`-аксессоры), а не переводить формулы. Подробности — `docs/Reference/Importers.md`.
- Headless-запуск Unity: `C:/Program Files/Unity/Hub/Editor/6000.6.2f1/Editor/Unity.exe -batchmode -nographics -quit -projectPath ... -executeMethod ...`. Unity с проектом должен быть закрыт (lock `Temp/UnityLockfile`). Проверки с GPU запускаются без `-nographics`. Перед batch-прогонами снимать копию ProjectSettings (не делать `git checkout` поверх чужих правок).
- Шейдеры, которые рантайм ищет по имени (`Shader.Find`), добавлять в список `Assets/Editor/EnsureRuntimeShaders.cs`, иначе их нет в сборке.
- Быстрая проверка скриптов под сборку: `-batchmode -nographics -quit -executeMethod RTXMnesia.EditorDev.BuildCheck.RunBatch` (ошибки и устаревшие API CS0618/CS0612/CS0619).
- Новые настройки RT — на вкладку «Трассировка»; в шрифтах игры нет «—», в текстах интерфейса — двоеточие или дефис.

## Синхронизация инструкций

- Поддерживать CLAUDE.md и AGENTS.md в корне репозитория побайтно одинаковыми. Любое изменение правил или описания проекта в одном файле сразу переносить в другой. Справочник `docs/Reference/` общий для обоих.
- Новые подробности о подсистеме писать в соответствующий файл `docs/Reference/`, а не в этот файл; здесь — только правила и указатель.
