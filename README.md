# RTXMnesia

Unity game prototype with HDRP.

Open `UnityProj/UMnesiaRTX` in Unity **6000.6.2f1**.
HDRP **17.6.0** is configured for desktop with DirectX 12 / DirectX 11.
See [HDRP setup](UnityProj/UMnesiaRTX/HDRP-SETUP.md) for details.

The `src/` and `source/` directories contain local reference sources and are
excluded from version control, along with Unity caches, logs and build output.
