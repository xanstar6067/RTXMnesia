# Главное меню (пункт 5 плана интерфейса)

## Запуск и импорт

`Tools > RTXMnesia > Import > Main menu and build scenes` или batch-метод `RTXMnesia.Importer.MainMenuConverter.ConvertBatch`.

Результат — игнорируемая сцена `Assets/AmnesiaImported/Levels/main_menu/main/menu_bg.unity` из `source/main_menu/main/menu_bg.map`: 50 статических объектов, 3 сущности, 4 плоскости, 3 декали, 8 точечных источников, 2 билборда, 4 системы частиц. Ресурсы и сгенерированная сцена в git не попадают.

Камера берётся из CameraPos, смотрит в локальный −Z HPL2; это отличается от +Z PlayerStart для игрового персонажа. FOV — Main/BGCamera_FOV из menu.cfg. В декоративной сцене нет игрока, скрипта уровня, инвентаря или журнала. Тела, свет, частицы и звук обновляет существующий HplMap в режиме menuBackground.

Русский логотип ищется сначала в resourceDirs языка, затем общий запасной вариант. MenuConverter добавляет его в HplMenus.asset; шрифты и skin проходят прежний общий импорт. Музыка — Main/Music, game_menu.ogg.

В общем списке сцен сборки и текущем списке Unity:

1. Главное меню — menu_bg.unity.
2. Первая игровая карта — maps/main/ch01/00_rainy_hall.unity.

Новая игра грузит первую карту с её обычным вступлением. При отсутствии импортированной первой сцены конвертер создаёт её. Редакторский Play в открытой игровой карте по-прежнему запускает эту карту; для проверки загрузки с меню нужно открыть menu_bg.unity.

Unity 6 может направлять свойство scenes в локальный build profile. Конвертер записывает также globalScenes, чтобы общий список сохранился в ProjectSettings/EditorBuildSettings.asset и работал после перезапуска / на другом профиле. Первичная спецификация API — [UnityCsReference, EditorBuildSettings](https://github.com/Unity-Technologies/UnityCsReference/blob/master/Editor/Mono/EditorBuildSettings.bindings.cs). GUID импортированных сцен разрешаются заново при импорте, их .meta в git не добавляются.

## Поведение

- HplMainMenu подключает HplGameUi в режиме заглавного экрана. Общий HplPauseMenu рисует меню, окна подтверждения и уже реализованные настройки. Декоративный HplMap не получает игровую паузу от этого контроллера: фон продолжает жить при открытом меню / настройках.
- Пункты: новая игра, настройки, выход. Новая игра и выход требуют подтверждения; Esc закрывает настройки / подтверждение, но не запускает игровое управление на заглавном экране.
- В меню Esc добавлен выход в главное меню. Оригинальный локализованный вопрос предупреждает о потере несохранённого прогресса. Отмена сохраняет текущую паузу и данные.
- Переходы асинхронные. Новая игра: затемнение за MainFadeOutTimeSlow и приближение камеры к BGCamera_ZoomedFOV со звуком ZoomSound. Возврат в меню: MainFadeOutTimeFast. На чёрном экране появляется надпись загрузки; повторный ввод блокируется.
- До проверки доступности целевой сцены игровые данные не очищаются. Во время загрузки прежний мир заморожен; перед активацией новой сцены очищаются HplGame и временные PlayerStateVars, восстанавливается timeScale = 1. Выгрузка уничтожает источники звука предыдущей сцены.
- Пользовательские настройки живут отдельно в PlayerPrefs и загружаются обоими экранами. Черновик / OK / Отмена используют тот же код, что в меню Esc.
- Пункты продолжения / загрузки появятся вместе с сохранениями. Профили, пользовательские истории и выбор сложного режима не добавлены; новая игра запускает текущую обычную кампанию.

Общие переходы между игровыми картами (`ChangeMap`) остаются отдельной задачей. Декоративный фон сохраняет ограничения существующего импортёра: BoxLight и FogArea пока пропускаются. Это не перенос следующего игрового уровня.

## Проверки

`RTXMnesia.EditorDev.MainMenuPreview.RunBatch` (без -quit / -nographics, сам закрывает редактор) импортирует меню, запускает прежние 27 PauseTests, 50 InventoryTests, 36 JournalTests и 14 MainMenuTests. Затем Play-прогон проверяет 14 условий настоящего цикла: старт меню → настройки / отмена → новая игра со вступлением → отмена выхода → возврат в меню → повторная новая игра с чистым состоянием.

Отчёты — Logs/MainMenuCheck/Tests.txt, PlayTests.txt; снимки — MainMenu.png, MainMenuOptions.png, NewGameConfirmation.png, ReturnToMenuConfirmation.png, ReturnedMainMenu.png. Мир рендерится GPU, UI собирается из реальных CanvasRenderer / атласов через HudSnapshot.DrawCanvas. Тестовое содержимое и сцены не сохраняются. Отдельный исполняемый билд этим прогоном не создаётся.
