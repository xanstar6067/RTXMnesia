# Эффекты, HUD, интерфейс, меню паузы, инвентарь, журнал, главное меню

> Вынесено из CLAUDE.md (2026-10-25) без изменений текста; перекрёстные ссылки «см. «Раздел»» ищи по заголовкам в `docs/Reference/`. Индекс — в CLAUDE.md.

**Эффекты** (`HplEffects`, порт `cLuxEffectHandler`) рисует `HplScreenEffectsPass`: HDRP custom pass AfterPostProcess, создаётся в рантайме, глобальные настройки HDRP не нужны. Шейдер `Assets/Shaders/HplScreenEffects.shader`.
- Рендерер эффектов (`HplEffectRenderer`, порт `cLuxEffectRenderer`, проход `HplEffectRendererPass` BeforePostProcess, шейдер `Assets/Shaders/HplEffectRenderer.shader`): контур предмета в фокусе (только предметы, с которыми можно взаимодействовать; маска видимых пикселей вместо stencil, увеличенный на 2 см объект синим 0.5 вне маски, два размытия на ¼ разрешения, сложение вне маски в прямоугольнике объекта) и мерцание предметов ближе 4 м (диффуз × (0.5, 0.5, 1) × rim × пульсация). Свечение врагов в темноте (`AddEnemyGlow`) не рисуется: альфа считается в `HplEnemy`.
- Порядок HPL2: ImageTrail → RadialBlur → Sepia (1D LUT `colorconv_sepia.tga`, по каналам) → затемнение (× (1 − alpha)) и вспышки (+).
- Расчёт в sRGB-значениях, как в гамма-рендере HPL2.
- След адаптирован к динамическому FPS: эталонный вес при 60 Гц `a60 = exp(-amount × 60 × 0.015)`, вес нового кадра `1 − (1 − a60)^(frameTime × 60)`. frameTime — реальное время между рендерами; накопление в RGBA16F, без залипания 8-битного буфера на высоком FPS.
- Тряска экрана — `HeadPosAdd.ScreenShake`.
- Голоса (`PlayVoiceEffect`) — потоки GUI (или 3D в позиции) через обработчик звука; реплика идёт, пока её запись жива (время клипа считает обработчик), затем следующая и колбэк окончания.

**HUD** (`HplHud`, порты `cLuxMessageHandler` и `cLuxHintHandler`).
- Субтитры, `SetMessage`, подсказки (данные/заблокированные — в `HplGame`), иконка «запись добавлена», текст emotion flash.
- `ParseString` (порт `cLuxHelpFuncs`) — `$ButJournal` → клавиша из `default_user_keys.cfg`, название из категории `ButtonNames`.
- Виртуальный экран 800×600 по центру, Unity UI overlay. Текст — шрифтами игры: `FontConverter` (.fnt AngelCode → `Fonts/<имя>.asset` `HplFont`, страницы склеены в атлас `Textures/fonts/<язык>/<имя>__gui.png`, шрифт ищется сначала в папках `RESOURCES` языка — `fonts/rus`), метрики нормированы на lineHeight как `cSDLFontData`; `HplGuiText` (Graphic) рисует вызовы `DrawFont` за кадр, перенос строк — порт `iFontData::GetWordWrapRows`; раскладка субтитров, сообщений, подсказок, текста вспышки эмоции и фокуса — по их `OnDraw`.
- Canvas не рисуется в снимках `RenderToFile` вне цикла плеера: `PlayerSimulation` дорисовывает текст HUD на CPU (`Editor/Dev/HudSnapshot`, те же квады `HplGuiText.ForEachQuad`); прицел и иконки в снимках не видны.

**Интерфейс игры** — `HplGameUi`: общая пауза мира, затухание экранов, маршрутизация клавиш и публичный API. Экраны в отдельных классах: `HplMenuScreen` (меню паузы / заглавный экран, настройки, подтверждения), `HplReadingScreens` (инвентарь и журнал), `HplSceneTransition` (загрузка сцен). Новый экран — новый класс, в `HplGameUi` только переключение. Своих текстов в интерфейсе нет, только локализация игры; ошибки настройки сборки — в лог.

**Меню паузы** — `HplMenuScreen` + `HplPauseMenu`: Esc, мышь или стрелки/Tab + Enter; возврат / настройки / подтверждённый выход в главное меню (и «Сохранить и выйти»; пункта выхода из приложения в игровом меню нет, как в оригинале без `ExitMenuDirectly` — выход из приложения на титульном экране). Оформление из игры: шрифты `menu.fnt` и `menu_gui_default.fnt` через общий `FontConverter` → `HplFont` → `HplGuiText` (обязателен CanvasRenderer), курсор и графика `gui_main_menu.skin`, снимок с семью H/V-размытиями в `HplScreenEffectsPass`, плавные переходы. Ресурсы: `MenuConverter.ConvertBatch` → игнорируемый `Assets/AmnesiaImported/Resources/HplMenus.asset` (карта не требует переимпорта). `HplUserSettings` — черновик, OK/Отмена: субтитры/подсказки/прицел/комментарии и мышь — в профиле (`user_settings.json`, как user_settings.cfg HPL2), общая громкость, графика и гамма — общие, JSON в PlayerPrefs (см. «Настройки графики», «Профили»). Кнопки окон (OK / Отмена настроек и клавиш, окна «Да / Нет», списки) — графикой скина `ButtonUp*` (`SkinButton`). Отдельный `UiInputBlocked` не меняет скриптовый `active`; пауза останавливает мир/физику/звук, при отключении UI прежнее состояние восстанавливается. В игре ещё «Сохранить и выйти» (см. «Сохранения»). Настройки: графика (ниже), «Комментарии» (игра, menu.cfg ShowCommentary), конфигурация клавиш (управление). Подробнее: `docs/UiPort.md`. Проверки: `RTXMnesia.EditorDev.PauseTests.RunBatch`, GPU/Play-снимки — `RTXMnesia.EditorDev.MenuPreview.RunBatch` (без -quit/-nographics).


**Инвентарь** — `HplInventory` + `HplInventoryView`, Tab; Tab / Esc закрывают сообщение либо экран. Сетка 6×3, графика и координаты menu.cfg, здоровье / рассудок / масло и существующий счётчик огнива. Общий путь шрифтов game_default / game_header; `InventoryConverter.ConvertBatch` → игнорируемый `Resources/HplInventory.asset` (136 изображений, 77 определений .ent, без переимпорта карты). Двойной клик / Enter — расходник или выбор сюжетного предмета, перетаскивание на другой предмет — сочетание; пустой слот не меняет порядок. Расходник снимает одну единицу стопки, скриптовый RemoveItem по имени — всю запись (разные перегрузки HPL2). `PlayerStateUseItem` использует общий луч с препятствиями и зарегистрированными областями, иконку предмета даже при отключённом обычном прицеле; ЛКМ / ПКМ вызывают use-item коллбэк карты в пределах max(MaxFocusDistance, MinUseItemDistance), затем Normal; автоматического удаления сюжетного предмета нет. `Levels/InventoryScript.cs` — ручной порт общего maps/main/inventory.hps, 52 сочетания на новую игру; реестр в HplGame, не в скрипте карты. Мир / физика / таймеры заморожены, скрежет и скрип физических тел затухают; окружение / музыка продолжаются, World → 0.5, текущие голос и сопровождающий звук приостановлены независимо от других пауз. Фон — резкий снимок с оригинальной сепией и затемнением. Шкала масла — `cLuxInventory::OilOnDraw` / `OilOnUpdate`: область обрезки (RectMask2D) на высоте масла внутри колбы, в ней жидкость вдвое больше колбы двумя копиями (0.75 и 0.25) с покачиванием sin / cos и три пузырька, поверх стекло и рамка; CPU-снимки (`HudSnapshot.DrawCanvas`) учитывают RectMask2D. Скриптовые запреты вступления сохраняются. Журнал открывается отдельным экраном с возвратом в инвентарь; фонарь переключает флаг, модель / свет в руке — шаг 4.4. Документация: docs/ScriptPort/inventory.md, docs/UiPort.md. Проверки: InventoryTests.Run (50 проверок), MenuPreview — Play-снимки Inventory / InventoryMessage; тестовые предметы не сохраняются.

**Журнал** — `HplJournal` + `HplJournalView`: J — оглавление, M — активные задания, N — последний текст без повторной озвучки. Кнопка / J из инвентаря возвращают затем в инвентарь с сохранением паузы мира и реплик; переход идёт через чёрное затухание, без вспышки яркого кадра. Esc / ПКМ идут по иерархии; J / M / N / Tab закрывают напрямую, но narrated сначала переключает следующий голосовой сегмент. Шрифты game_journal / game_header через общий FontConverter, бумага и навигация graphics/journal, координаты menu.cfg и оригинала. JournalConverter.ConvertBatch → игнорируемый Resources/HplJournal.asset (24 изображения), карта не требует переимпорта. HplGame.JournalEntry хранит записи, тип / серию, номер с 1 внутри серии и прочтение; LastReadEntry — последний текст. Дневники группируются по серии, обычное чтение — 18 строк и [new_page], озвучка — [voice …] и автопереход по завершению SoundEntry. DiaryCallback получает номер внутри серии с 1; ReturnOpenJournal(false) отменяет автооткрытие текущего подбора, следующий подбор снова включает его. AddNote / AddDiary из API только добавляют данные. Подбор Note открывает текст при amount > 0 (>= 2 с озвучкой), Diary — озвученное чтение, если callback не отменил. Выполненные задания скрыты, данные сохраняются; сохранения прохождения и процент завершения пока не реализованы. Запреты вступления действуют на горячие клавиши. Проверки: JournalTests.Run (36), MenuPreview — 7 Play-снимков разделов и страниц плюс прежние 50 InventoryTests / 27 PauseTests. Документация: docs/ScriptPort/journal.md, docs/UiPort.md.

**Главное меню (пункт 5 исходного плана интерфейса)** — `HplMainMenu`, общий HplGameUi / HplPauseMenu в режиме titleScreen. Оригинальная декоративная сцена main_menu/main/menu_bg.map, русский логотип из lang/rus, музыка game_menu.ogg; новая игра (окно выбора режима, см. «Сложный режим») / общие настройки / «Сменить профиль» / подтверждённый выход; свои пункты «Дополнение «Жюстина»» (титульный экран кампании Justine) и в нём «Основная игра» — в HPL2 Justine запускалась отдельно (`Amnesia.exe ptest`). LevelConverter.ConvertMenuBackground создаёт камеру на CameraPos (локальный −Z HPL, без игрока); HplMap.menuBackground обновляет мир / частицы / звук, без скрипта уровня и без присвоения игрового GameUi. MainMenuConverter.ConvertBatch / Import > Main menu and build scenes генерирует игнорируемую сцену и настраивает EditorBuildSettings.globalScenes и scenes: меню, 00_rainy_hall, затем все импортированные игровые карты (то же делает импорт каждой карты); GUID ресурсов разрешаются при импорте. Новая игра и возврат из Esc идут через асинхронную загрузку с затемнением; у новой игры — MainFadeOutTimeSlow, зум FOV и ZoomSound из menu.cfg. Повторный ввод блокируется. До проверки доступности целевой сцены данные не очищаются; перед активацией сбрасываются HplGame и временные PlayerStateVars, timeScale = 1. Звуки старой сцены освобождаются при выгрузке. Отмена выхода сохраняет текущую паузу и прогресс; предупреждение о несохранённом прохождении — из локализации оригинала. Настройки PlayerPrefs сохраняются независимо. «Продолжить» и «Загрузить игру» — см. «Сохранения»; у Justine их нет (`mbPTestActivated`). Пользовательские истории отложены (решение пользователя: Steam Workshop и старая установка — отдельная задача). Проверки: MainMenuTests (46: порядок пунктов, окно режима, «Продолжить» / «Загрузить игру», профили — создание, повторное и пустое имя, выбор, свои настройки и клавиши, удаление, вопрос о выходе без профиля), MainMenuPreview.RunBatch — 32 условия настоящего Play-цикла: меню → профили → окно режима → первая карта → меню → титульный экран Justine и обратно → вторая новая игра → «Сохранить и выйти» → «Продолжить» с восстановленным состоянием плюс 27/50/36 прежних проверок; снимки в Logs/MainMenuCheck (Profiles, ProfileName, StartGameHard, JustineMenu, LoadGame, …; сохранения и профили прогона — в Logs/MainMenuCheck/Saves и Profiles). Подробнее: docs/MainMenu.md. Ресурсы / сцены меню остаются вне git.
