# Настройки графики

## Тест производительности (2026-10-28)

Первая кнопка вкладки «Графика» — **«Тест производительности.»**. Запускает шесть пролётов
общей длительностью 180 секунд (загрузки и переходы отдельно), с текущим черновиком
параметров окна настроек, без принудительного повышения качества и без сохранения черновика.
Фонтан → карта 01 с печью → архивы → машинное отделение → цистерна → хор с брутом.
Во время загрузок и показа — подсказка удерживать **Esc 1.5 секунды**, с индикатором удержания.
После окончания или отмены возвращается прежнее окно настроек и состояние исходной сцены.
Статистики кадров и экрана результатов пока нет (решение пользователя).

Реализация: `World/HplBenchmark.cs`, `World/HplBenchmarkRoute.cs`; интеграция с меню —
`MenuControl.Benchmark` и `HplMenuScreen`, изоляция временных карт — `HplMap.IsBenchmark`.
Карты грузятся аддитивно; исходные сцены остаются выключенными в памяти. Это временно
требует памяти для исходной карты и одной карты теста. Сохранения и прогресс не меняются.
Сценарий, ограничения и проверки: [BenchmarkScenario.md](../BenchmarkScenario.md).

Проверка в редакторе (без сборки плеера): `RTXMnesia.EditorDev.BenchmarkPreview.RunBatch`
с GPU, без `-quit`/`-nographics`; `-benchmarkQuick` сокращает ожидание эпизодов при той же
проверке всей траектории через каждые 0.1 с, встреча с врагом идёт полностью.
Проверяются меню запуска, свободный путь камеры, звук и эффект врага, полный возврат,
сохранение черновика и отмена; вывод тестового процесса беззвучный, PlayerPrefs не записываются.
Отчёт: `Logs/BenchmarkCheck/report.txt` (вне git).
`BenchmarkPreview.RunTitleBatch` отдельно проверяет запуск и отмену из главного меню;
отчёт — `Logs/BenchmarkCheck/title_report.txt`.

**Настройки графики** — `Hpl/HplGraphics.cs` (применение), `Ui/HplGraphicsOptions.cs` (выпадающие списки), окно настроек в `HplPauseMenu.Options.cs` (2026-10-21), поля — в `HplUserSettings`.
- Окно настроек (макет согласован с пользователем 2026-10-21): семь вкладок «Игра · Дисплей · Графика · Изображение · Трассировка · Звук · Управление» (`HplPauseMenu.*TabIndex`, `MenuControl.GameTab … InputTab`), окно 680 × 460. Содержимое вкладки прокручивается в области 612 × 318 под вкладками: сетка из двух колонок ячеек (список 250 × 45, флажок, слайдер 48, кнопка скина, примечание на всю ширину) с заголовками секций; `RectMask2D`-контейнер «Options scroll area» со своими кусками и текстом (`_scrollText`, между текстом меню и текстом GUI; открытый список рисуется поверх) обрезает рисование, ячейки вне области не рисуются, но остаются в списке кнопок (стрелки / Tab прокручивают к выбранной — `ScrollToSelected`, колесо — 40 px, полоса справа с кнопками-стрелками и перетаскиваемым ползунком, `TryScrollTrack`). Недоступные ячейки серые и не нажимаются, клавиатура их пропускает (`SkipNavAt`), `Activate` их игнорирует. Вкладки: «Дисплей» — экран (разрешение, режим, FPS — серый при VSync, VSync, гамма) и HDR (режим списком, состояние, четыре слайдера, «Данные дисплея», «По умолчанию», «Калибровка HDR…»); «Графика» — освещение, текстуры, тени, эффекты; «Изображение» — один список «Метод» (выкл / FXAA / SMAA / TAA / DLAA / DLSS ×4: поля `antialiasing` и `dlssMode` те же, выбор AA выключает DLSS, `MenuControl.ImageMethod`), модель DLSS, строка «Рендер / Вывод», примечание про Smooth Motion; «Трассировка» — главный переключатель (`MenuControl.RtEnabled`, поле `lighting` = 1; имя поля осталось из-за сохранённых настроек и проб, на смысл «освещения» не указывает), без него остальное серое. Калибровка HDR — отдельное окно (`HplMenuExtras.hdrCalibration`, `HplPauseMenu.HdrCalibration`): образец рисуется «дыркой» в фоне, поэтому он вне прокрутки; Esc / «Закрыть» возвращают на «Дисплей».
- Списки — порт `cWidgetComboBox`: графика скина (`ComboBoxBackground`, `ComboBoxButtonIcon`, вертикальный слайдер), до 12 строк высотой шрифт + 2, больше — прокрутка колесом / стрелками, у края экрана список поднимается; рисуется отдельным верхним слоем (свои куски и текст над текстом окна), пока открыт, нажимается только он; клик мимо или Esc закрывает; стрелки вверх / вниз и Enter — выбор, влево / вправо на закрытом списке — соседнее значение. Недоступный пункт показан серым и не выбирается.
- Пункты: освещение («Классическое» / «Улучшенное» — поле `lightingSet`, см. «Улучшенное освещение»; трассировка лучей в этот список не входит и работает поверх любого освещения, см. «Трассировка лучей») и текстуры («Классические» / «Улучшенные»: отдельные PBR-материалы, обратимая замена через `HplEnhancedTextures`; 645 готовых PBRify-наборов для 661 материала (с 2026-10-24 — и исходники 2K проходом ×2), включая cutout, остальные — классические; native DDS BC7/BC5/BC4 с streaming, `Prepare-EnhancedTextures.py` перед импортом, оригиналы и исходные PNG сохраняются; новые материалы загружаются лениво из Resources; импорт первого камня `EnhancedMaterialConverter.ConvertBatch`, завершённых `result.json` — `ConvertReadyBatch` (проверка SHA256/ссылок, emission и UV сохраняются), подробности и проверки — `docs/EnhancedTextures.md`), разрешение (размеры дисплея по убыванию, частоты слиты, при полном экране — наибольшая частота размера; 0 × 0 — разрешение рабочего стола), экран (полноэкранный / окно без рамки / оконный; старое поле `fullscreen` мигрирует), ограничение FPS (без ограничений, 60, 120, 144, 240, 280, 360 — `Application.targetFrameRate`, при VSync не действует), VSync, гамма; качество текстур (низкое / среднее / высокое = `globalTextureMipmapLimit` 2 / 1 / 0), бюджет видеопамяти (выпадающий список 2 / 4 / 8 / 10 / 12 / 16 ГБ, по умолчанию 2; глобальное `textureMemoryBudgetGb` → `streamingMipmapsMemoryBudget`, OK/Отмена), анизотропная фильтрация (выкл, 2x–16x: `ForceEnable` + `SetGlobalAnisotropicFilteringLimits(n, n)` — ровно n у всех текстур), сглаживание (выкл / FXAA / SMAA High / TAA — `HDAdditionalCameraData.antialiasing` всех игровых камер перед рендером, кроме зеркал воды; MSAA нет: HDRP рендерит deferred; список «Метод» вкладки «Изображение» содержит и DLSS: пока он выбран, `antialiasing` не меняется и возвращается после выбора метода AA), тени (выкл / низкие / средние / высокие: высокие — `ShadowResolution` карты, каждая ступень ниже — на уровень HDRP ниже; свет без CastShadows не меняется), свечение (Bloom HDRP профиля по умолчанию или 0), след при движении и радиальное размытие (`cLuxEffect_ImageTrail` / `RadialBlur` не рисуются, логика эффектов идёт как обычно).
- Глобальный Volume «HPL graphics settings volume» (приоритет 1000, переживает смену сцен) убирает размытие движения HDRP (в профиле HDRP по умолчанию intensity 0.5 — размывало каждый поворот камеры; в HPL2 его нет) и глубину резкости, задаёт Bloom.
- Подписи — из локализации игры (OptionsMenu), свои тексты — только для того, чего в оригинале нет (наборы, режимы экрана, FPS, методы сглаживания), и «Свечение (Bloom)»: русская строка игры «Bloom» — «Потускнение».
- Применение: при запуске до первой сцены (`RuntimeInitializeOnLoadMethod`, сохранённые настройки) и при каждом `HplUserSettings.Apply`. Качество меняется только в Play; в редакторе при выходе из Play mip-лимит, анизотропия и частота кадров возвращаются (иначе попали бы в ProjectSettings). Экран (режим, разрешение) в редакторе не меняется.
