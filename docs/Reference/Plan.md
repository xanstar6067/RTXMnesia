## Решения пользователя

- Языки: **русский** (основной, есть русская озвучка `lang/rus`) + **английский** как запасной. Остальные языки не импортируем.
- Объём: в итоге вся игра, но идём по шагам; первая цель — **глава 1** (`maps/main/ch01`, 15 карт, начиная с `00_rainy_hall`).
- Скрипты уровней портируются **вручную на C#** (без встраивания AngelScript). Каждая карта документируется в `docs/ScriptPort/` по шаблону из README; код оригинала туда не копируется, только ссылки `файл:строка`.
- После переноса функции API обновлять её статус в `docs/ScriptPort/api.md`.
- План этапов: 1) подготовка ✓ → 2) импортёры (текстуры, материалы, модели ✓; префабы .ent → вместе с шагом 4) → 3) импорт одного уровня ✓ (`00_rainy_hall`, с частицами) → 4) игрок: 4.1 передвижение ✓, 4.2 физика сущностей ✓ (Rigidbody, джоинты, физ. материалы), 4.3 взаимодействие ✓ (фокус/прицел, Grab, Push, Slide, двери, рычаги, колёса, лампы, предметы), 4.4 фонарь ✓ (руки, модель в руке, масло), лестницы ✓ → 5) скрипты уровней (идёт: рантайм, эффекты, HUD со шрифтами игры, `00_rainy_hall` ✓, `01_old_archives` ✓, `02_entrance_hall` ✓, `03_archives` ✓, `04_wine_cellar_lab` ✓, `05_wine_cellar` ✓, `06_distillery` ✓, `07_archives_cellar` ✓, `08_cellar_maze` ✓, `09_back_hall` ✓, `10_daniels_room` ✓, `11_study` ✓, `12_storage` ✓, `13_machine_room` ✓, `14_elevator` ✓, глава 2: `15_prison_south` ✓, `15_prison_north` ✓, `16_cistern_entrance` ✓, `17_control_room` ✓, `18_cistern` ✓, `19_morgue` ✓, `20_sewer` ✓, `21_torture_nave` ✓, `22_torture_chancel` ✓, `23_torture_transept` ✓, `24_torture_choir_west` ✓, `24_torture_choir_east` ✓, глава 3: `25_cell_tunnels` ✓, `26_torture_nave_redux` ✓, `26_zimmerman_vision` ✓, `27_torture_chancel_redux` ✓, `28_inner_sanctum` ✓, `29_orb_chamber` ✓, Justine: `01_cells` ✓, `02_library` ✓, `03_dungeon` ✓, `04_final` ✓, переход между картами ✓, состояние посещённых карт ✓) → 6) звук ✓, рассудок и темнота ✓, урон и смерть ✓, враги: ядро и Grunt ✓, вода и водяной монстр ✓, события безумия ✓, меню и сохранения ✓ (без профилей и сложного режима), верёвки, связи колёс, липкие зоны и урон слизи ✓ → 6.5) полностью играбельная версия (до RTX не спешить), по порядку: а) титры и концовки, NPC, прикреплённые пропы, анимации пропов, критеры ✓;
