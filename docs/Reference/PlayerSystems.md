# Руки и фонарь, рассудок и темнота, события безумия, урон и смерть

> Вынесено из CLAUDE.md (2026-10-25) без изменений текста; перекрёстные ссылки «см. «Раздел»» ищи по заголовкам в `docs/Reference/`. Индекс — в CLAUDE.md.

**Руки и фонарь** — `PlayerHands` (порт `cLuxPlayerHands`, `iLuxHandObject`, `cLuxHandObject_LightSource`) и `PlayerLantern` (`cLuxPlayerLantern`).
- `HandsConverter` (меню Import > Player hands and hand objects) → игнорируемый `Resources/HplHands.prefab` (`HplHandsData`): `models/player/hands/hands.ent` (скелетная модель через импорт Unity как Legacy, анимации `.dae_anim` копируются как `.dae` и сохраняются клипами с именами из `.ent`) и все `models/hand_objects/*/*.ho` с сущностью модели (свет, билборды — общая сборка `LevelConverter.BuildEntitiesPrefab`). Переимпорт карт не нужен.
- Анимации `.dae_anim` (руки, враги, пропы) копируются через `ColladaAnimFix`: ключи сдвинуты на start_time, интерполяция линейная, тройки Эйлера заменены эквивалентными, ближайшими к предыдущему ключу (иначе пересэмплирование Unity между ключами крутило кисть — рывок доставания / убирания фонаря); `PlayAnim` без других активных анимаций сразу ставит полную позу (нормализация весов HPL2). Проверка: `RTXMnesia.EditorDev.HandsPreview.RunBatch` (без -quit/-nographics) → `Logs/HandsCheck` (0 скачков). Пути кривых перенацеливаются на имена костей модели (`HandsConverter.RetargetCurvePaths`): импорт Unity переименовал кость `hand` в `elbow_hand`, и кисть с пальцами не анимировались (плоская открытая ладонь вместо хвата ручки фонаря; теперь суставы сгибаются на ~72°, как в оригинале).
- Руки следуют за камерой, поворот сглажен по `HandsRotationSmoothNum` шагам (веса растут квадратично), смещения головы Bob / ScreenShake / Hurt × `HandsPosAddMul` вычитаются. Смена предмета: holster → draw → idle (`CrossFade` 0.2 с, неповторяющиеся клипы держат последний кадр). Источник света: свет, билборды и подсветка материала проявляются / гаснут за FadeIn/OutTime, мерцание включается после проявления, маятник `Sway*` (угол взгляда, скорость игрока, трение, пределы), подмеш `SkipSwaySubMesh` не качается.
- Фонарь: F / предмет инвентаря / `SetLanternActive`; без предмета — подсказка LanternNoItem, без масла — LanternNoOil и звук; расход `LowerOilSpeed`/с (не во время вспышки эмоции), кончилось масло — звук и выключение; `LanternLitCallback` карты. Собственный свет `cLuxPlayerLantern` (Radius 0.0001) ничего не освещает и не создаётся. На лестнице фонарь запрещён (`PlayerState.AllowLantern`).
- Свет вблизи: у HPL2 спад внутри радиуса почти плоский, у HDRP 1/d². Свет в руке (10–20 см от кисти) засвечивал бы руку. Руки — на слое рендеринга 7 (`HplLighting.HandsRenderingLayer`), свет предмета в руке его не освещает (маска младших 8 бит слоёв без 7, `HplLighting.SetLightLayers` через `HDAdditionalLightData.lightlayersMask`), а копия света с `shapeRadius` = расстоянию до кости крепления освещает только руки на уровне HPL2. Свет карты освещает и руки. В HDRP-ассете включены Light Layers (`ConfigureHDRP`).

**Рассудок и темнота** — помощники игрока в порядке `cLuxPlayer` (`AmnesiaPlayer.StepLogic`): `PlayerLightLevel`, `PlayerInDarkness` (`Player/PlayerDarkness.cs`), `PlayerSanity`, `PlayerCamDirEffects`, `PlayerInsanityCollapse` (`Player/PlayerSanity.cs`); числа — `game.cfg` `Player_Darkness` / `Player_Sanity` / `Player_General`.
- Освещённость (`cLuxPlayerLightLevel` + `cLuxMapHelper::GetLightLevelAtPos`): дважды в секунду в пяти точках тела сумма по свету (`AmnesiaLight.LightLevelAt`: box — max цвета внутри коробки; точечный и прожектор (фрустум `spotFov`/`spotAspect`/`spotNearClip` из импорта) — max цвета × (1 − d / (r + RadiusAdd)), прожектор с тенями — при прямой видимости), обычная и с RadiusAdd; горящий фонарь +1. Реестр — `AmnesiaLight.All`.
- Темнота по видимому свету (2026-10-24, не из HPL2; флажок «Темнота по видимому свету» вкладки «Игра», поле `visibleDarkness`, по умолчанию вкл, общее; действует только при улучшенном освещении — `PlayerLightLevel.VisibleOn`): улучшенное освещение переносит лампы в пламя и даёт физический спад, радиусы HPL2 с видимым светом больше не совпадают. Тогда те же пять точек тела — «датчик» Даниэля (`HplLightAnalysis.SensorLux`): освещённость поверхности, обращённой к каждому HDRP-источнику (кандела / ниты, 1/d², окно радиуса, конус, прямоугольные), если луч от точки до него доходит (стены закрывают, своя лампа — нет), плюс box-свет, внутри которого точка; свет как он светит сейчас (зажжён, потушен, затухание, мерцание), без отражённого (GI), без света в руке и света темноты игрока. Уровень = люксы / `PlayerLightLevel.LevelLux` (π × `UnitRadiance` ≈ 30 лк: уровень 1 — свет HPL2 цвета 1, который показывает белую поверхность белой), так пороги `game.cfg` (рассудок 0.15, свет темноты 0.2, зрение врагов 0.35) сохраняют смысл. Расширенный уровень (в HPL2 — радиусы + RadiusAdd, «свет рядом») — максимум по телу и восьми точкам вокруг на RadiusAdd (3 м), не доходя 0.2 м до стен. Горящий фонарь по-прежнему +1. Уровень — первая оценка, калибруется вместе с яркостью факелов. Проба `EnhancedLightingPreview`: строка `darkness sensor` у каждого вида (классический и видимый уровни, обычный / расширенный), проверки: фонарь даёт ≥ 1, при выключенном свете (режим `only` без `-lightLit` и вне box-света) — 0.
- Темнота (`cLuxPlayerInDarkness`): при обычной освещённости ≤ AmbientLightMinLightLevel загорается слабый синеватый свет на 0.3 м ниже камеры (без теней, не сохраняется; у HDRP-света `shapeRadius` = радиус и ×4 к канделам — так спад 1/(d² + r²) у игрока даёт яркость HPL2); при расширенной ≤ MinLightLevel рассудок падает SanityLossPerSecond × множитель (растёт 0.1/с), подсказка DarknessDecrease раз в 3 с (не во время вспышки эмоции и при SetSanityDrainDisabled).
- Рассудок (`cLuxPlayerSanity`): удар (`GiveSanityDamage`) — звук и наезд камеры (след, FOV, aspect); потеря с эффектом — сердцебиение и звуки утечки; ниже SanityEffectsStart — эффект безумия; ниже SanityVeryLowLimit — подсказка, след 1.6, дыхание; восстановление до SanityRegainLimit; через SanityLowLimitMaxTime ниже SanityLowLimit — SanityLowNewSanityAmount. Враги в поле зрения (`UpdateCheckEnemySeen`: до 35 м, во фрустуме, 2 из 5 лучей) — NearEnemyDecrease и подсказка EnemySeen; перед ними критеры с потерей рассудка (паук) ближе 3 м к голове — NearCritterDecrease.
- Эффект безумия (`cLuxPostEffect_Insanity`, `HplEffects.Insanity`): проход в `HplScreenEffects.shader` до следа (приоритет 25), карты амплитуд и зума `shaders/posteffect_insanity_*.jpg` → `PostEffectsConverter` → игнорируемый `Resources/HplPostEffects.asset` (вызывается импортом уровня, меню Import > Post effect resources).
- Покачивание взгляда (`cLuxPlayerCamDirEffects`) при рассудке ≤ StartSwayMaxSanity: шаг мыши — среднее последних SwayMaxSavedPositions шагов; мышь здесь каждый кадр, поэтому ввод кадра копится в шаг, а среднее применяется с долей кадра в шаге.
- Обморок (`cLuxPlayerInsanityCollapse`) при рассудке < 0: голова вниз, крен до 35°, сон с петлёй и случайными звуками, мировые звуки тише и медленнее (`eLuxGlobalVolumeType_InsanityCollapse` = 4), движение × множитель, пробуждение с InsanityCollapse_AwakenSanity. Обморок поднимает тревогу у активных врагов (`AlertOfPlayerPresence`).
- События безумия — см. «События безумия».

**События безумия** — `Effects/HplInsanity.cs` (`cLuxInsanityHandler` и `iLuxInstanityEvent`), `HplArea` с типом Insanity (`cLuxArea_Insanity`); числа — `game.cfg` `Insanity`.
- Один статический обработчик на всю игру (как модуль HPL2): наборы, использованные события и ожидание переживают смену карт. Обновляется картой после игрока (порядок модулей контейнера "Default"), рисует `HplHud`.
- Ресурсы: `InsanityConverter` (меню Import > Insanity events, batch `RTXMnesia.Importer.InsanityConverter.ConvertBatch`, вызывается импортом уровня) → игнорируемый `Resources/HplInsanity.asset`: элементы `EventsFile` (`misc/main_sanity_events.cfg`, 54 события) с атрибутами как в файле и картинки `BugImage` / `FadeImageFile`. Переимпорт карт не нужен.
- Выбор: случайное неиспользованное событие включённого набора с MaxSanity ≥ рассудка (все использованы — сброс); после события ожидание `TimeBetween_*` по рассудку (`MaxSanity_*`). Новое событие возможно без ожидания, при рассудке ≤ `MaxSanity_LongWait` и без текущего.
- Типы: Bugs (жуки на HUD с краёв экрана к центру: блуждание + точка роя, проявление, исчезновение после Duration, петля GUI-потока), Particles (система у камеры, следует за ней, GUI-поток), SoundStream (GUI-поток после задержки; затемнение — модулятивный цвет FadeColor × a + белый × (1 − a) или картинка; субтитр шрифтом 18 от x = 250, пока не играет голос; DisablePlayer), Steps (звуковые сущности в случайном направлении, всё ближе и чаще).
- Область Insanity: в случайные интервалы, если форма игрока касается области и событие возможно, — случайное событие (AutoDisable выключает область).
- Скрипты: `SetInsanitySetEnabled`, `StartInsanityEvent`, `StartRandomInsanityEvent`, `StopCurrentInsanityEvent`, `InsanityEventIsActive`.
- Особенности оригинала: RandRectl(0, неиспользованных) включительно — одно значение из n + 1 не запускает ничего; запас ширины GUI = 800 × (соотношение − 4/3); `Reset` (новая игра) не возвращает выключенные наборы и использованные события (после главы 2 новая игра в той же сессии остаётся без бормотания главы 1).
- Исправлено (решение пользователя 2026-10-17, отступление от оригинала): две опечатки ключей. `misc/main_sanity_events.cfg` пишет `mfMaxSizeMul` вместо `MaxSizeMul` у трёх событий жуков (Bugs_Single / Many / Swarm) — HPL2 брал 1, жуки были 0.8–1×; теперь читается и ошибочный ключ, размер 0.8–1.3× (влияет только на размер картинки). Загрузчик области Insanity читал `IsanityArea_CheckTimeMax` (нет в `game.cfg` → 0, проверка каждые 0–1 с) — теперь `InsanityArea_CheckTimeMax` (1–15 с), ошибочный ключ — запасной.
- Отличие: каждая карта — своя сцена, поэтому при смене карты звук и частицы события пропадают со старой сценой (GUI-звуки обрываются), звуковое событие на этом заканчивается.
- Проверка: `RTXMnesia.EditorDev.InsanityTests.RunBatch` (`-batchmode -nographics -quit`) на `04_wine_cellar_lab` — 60 условий: импорт, наборы, пределы рассудка, случайный выбор, жуки, ожидание, затемнение рёва, субтитр бормотания, мухи, шаги, область, функции скриптов. Снимки HUD в Play — `RTXMnesia.EditorDev.InsanityPreview.RunBatch` (без -quit/-nographics) → `Logs/InsanityCheck`; модулятивное затемнение в них видно цветом, без умножения (холст ScreenSpaceCamera HDRP рисует в свой буфер). Прогон — `PlayerSimulation` командой `insanity [Имя|random|stop]`.

**Урон и смерть** — `Player/PlayerHurt.cs`: `PlayerHudEffect` (`cLuxPlayerHudEffect`), `PlayerHurt` (`cLuxPlayerHurt`), `PlayerDeath` (`cLuxPlayerDeath`); числа — `game.cfg` `Player_General` (`Hurt_*`, `HealthRegain*`, `Death_*`, `HeadSpin*`, `AutoKillYPos`).
- Удар (`AmnesiaPlayer.GiveDamage`, `GivePlayerDamage` по строке типа, урон от падения): брызги `graphics/hud/damage_<bloodsplat|claws|slash>N.tga` (две копии гаснут, потом сползают и растягиваются), красная вспышка HUD, поворот головы (`SpinHead`, затухание HeadSpinDeacc), не смертельный удар оставляет 10.
- Ранение: восстановление здоровья ниже HealthRegainLimit; ниже Hurt_EffectStartHealth — красный шум `hud_hurt_noise0N.dds` поверх экрана (модулятивный, плитками 256), замедление, одышка (голова `HeadPosAdd.Hurt` и `hurt_pant`) после движения.
- Смерть: голова опускается, крен до 65°, музыка останавливается, мир тише и медленнее (глобальная громкость id Death = 2), экран темнеет (модулятивно), подсказка смерти (`CheckPoint` / `SetDeathHint`, иначе `Hints/DefaultDeath`) волной букв; через 5.5 с (или клавишу: прыжок, присед, ЛКМ, ПКМ — ввод мёртвого игрока идёт только сюда) — здоровье 50, рассудок ≥ 40, `HplMap.LoadCheckPoint` (`cLuxMap`: стартовая точка чекпоинта, FadeIn 0.2, музыка чекпоинта, коллбэк `(имя, счётчик)`), белая вспышка, экран светлеет. Подсказка смерти переносится между картами. Падение ниже AutoKillYPos — смерть.
- Особенности оригинала: `SetPlayerHealth(0)` даёт ровно 0, а восстановление (`AddHealth` отсекает только < 0) сразу поднимает здоровье — смерть идёт дальше, но `IsDead` снова false; у чекпоинта `_auto` пустой коллбэк — `[Script] ERROR: Script call without a function name` при каждой смерти (HPL2 тоже выполняет пустой вызов).
- Рисует `HplHud` (`RefreshPlayerEffects`): картинки HUD под затемнением экрана HPL2 (z < 3.2) домножаются на (1 − fade), текст смерти — над ним. Шейдер `Assets/Shaders/HplGui.shader` (Alpha / Modulative). Картинки — `HudEffectsConverter` → игнорируемый `Resources/HplHudEffects.asset` (вызывается импортом уровня, меню Import > HUD effect resources).
- Смерть игрока шлёт врагам `PlayerDead` (они уходят в покой); чекпоинт выключает и сбрасывает врагов (`ResetProperties`: на старт, покой) и очищает врагов страха.
- Perma death Justine (`_permaDeath`): после голоса смерти — титульный экран Justine (отступление: HPL2 закрывал игру, Justine запускалась отдельно). Сложный режим — см. «Сложный режим».
