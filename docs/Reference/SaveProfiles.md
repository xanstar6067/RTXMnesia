# Сохранения, профили, сложный режим, флешбэки

> Вынесено из CLAUDE.md (2026-10-25) без изменений текста; перекрёстные ссылки «см. «Раздел»» ищи по заголовкам в `docs/Reference/`. Индекс — в CLAUDE.md.

**Сохранения** — `Assets/Scripts/Save` (namespace `RTXMnesia.Save`): `HplSaveHandler` (`cLuxSaveHandler`), `HplSaveGame` (`CreateSaveGameData` / `LoadSaveGameData`), `HplSaveData` (классы файла — `cLuxSaveGame_SaveData` и save data классы), `HplFieldBag` (простые поля объекта текстом).
- Папка — своя: `Документы/RTXMnesia/Profiles/<профиль>/Saves/<main|justine>` (без профиля — `Документы/RTXMnesia/Saves`), никогда не `Документы/Amnesia` оригинала. Batch-прогоны редактора (тесты, симуляции, снимки, где скрипты карт вызывают `AutoSave`) пишут в `Logs/BatchSaves` проекта; `HplSaveHandler.FolderOverride` — для тестов.
- Файл — JSON (`JsonUtility`, версия формата `SaveGame.CurrentVersion`), записывается сразу через временный файл; имя как в оригинале: `AutoSave_<DisplayNameEntry карты или NULL>_Г_М_Д_ч_м_с_n.sav`, не больше `Saving/MaxAutoSaves` (20) — самые старые по дате создания удаляются. В списке загрузки — `GetProperSaveName` («AutoSave - <название уровня> - Д/М-Г чч:мм:сс»), новые сверху.
- Когда: `AutoSave` из скриптов карт (почти все карты в `OnEnter`); «Сохранить и выйти» в меню паузы (нет у мёртвого игрока) — сохранение и выход из приложения (отступление: в HPL2 — титульный экран; на титульный экран ведёт «В главное меню»); «Выход» из игры сначала сохраняет, как `cLuxMainMenu::OnQuit` при закрытии окна. Титульный экран: «Продолжить» (новейшее сохранение, с подтверждением) и «Загрузить игру» (список, клик выбирает, повторный клик / OK — подтверждение и загрузка) — только когда сохранения есть.
- Что пишется (как `cLuxSaveGame_SaveData`): текущая карта целиком (`HplSavedMaps.CaptureCurrent`, `cLuxSavedMap`): все сущности со своими простыми полями класса и базовых классов (отражением; активность, эффекты, лампы — через их методы), тела и джоинты пропов; враги — тело, рыскание, звуковое состояние, патруль по id узлов, текущая анимация с временем, поля мовера и путь (состояние ставится, а не входится, как в HPL2); созданные скриптом и осколки — по `.ent`; чекпоинт, коллбэк фонаря, туман, переменные, таймеры, use-item коллбэки, свет, звуки и системы частиц, физические верёвки (частицы, длина, мотор, концы), что держат липкие зоны, interact connections пропов. Плюс кэш посещённых карт, игрок (`Carry` + позиция, взгляд, `active`, затухания FOV / aspect / крена, скорость события, страх, вода, монеты), инвентарь (и флаг запрета), журнал, глобальные переменные, подсказки, музыка (текущая песня с позиции, приоритеты), эффекты (затемнение, след, сепия, размытие, вспышка, очередь реплик и коллбэк, глобальные громкость / скорость), безумие (ожидание, использованные события, выключенные наборы), экран загрузки.
- Загрузка: файл читается, сохранение ждёт (`BeginLoad`) сцену своей карты (`HplMapChange.FindScene`), сцена грузится как при выходе в меню; `HplMap.Build` забирает его, `Begin` вызывает `LoadGame` вместо `OnStart` / `OnEnter`. Сущности сцены, которых нет в сохранении (подобраны, разбиты, уничтожены), удаляются. Поля C#-класса скрипта уровня начинаются заново — как глобальные переменные AngelScript, которые HPL2 тоже не сохраняет.
- Отличия и что не перенесено: состояние игрока всегда Normal (в оригинале тоже TODO для режима движения; лестница и т. п. не восстанавливаются); идущие флешбэк, обморок и смерть не восстанавливаются, поэтому их записи глобальной громкости (1, 2, 4) при загрузке пропускаются вместе с оригинальными 5 и 6; сообщения состояний врагов, снимок экрана (`abSaveSnapshot`), быстрые сохранение / загрузка (в HPL2 только отладочные). Сложный режим — см. «Сложный режим». Особенность оригинала сохранена: два сохранения в одну секунду получают одно имя (`GetSaveName` сбрасывает счётчик) — второе перезаписывает первое.
- Проверка: `RTXMnesia.EditorDev.SaveTests.RunBatch` (`-batchmode -nographics -quit`) на `10_daniels_room` — изменённое состояние карты, сущностей и модулей пишется в `Logs/SaveCheck`, сцена открывается заново и загружает его; имена, новейший файл, список, предел автосохранений.

**Профили** — `Save/HplProfiles.cs` (`cLuxBase::CreateProfile` / `SetProfile`) + окно `cLuxMainMenu_Profile` в `HplMenuScreen` / `HplPauseMenu` (`Profiles`, `EnterName`).
- Папка профиля — `Документы/RTXMnesia/Profiles/<имя>`: `user_settings.json` (игровые опции и мышь), `user_keys.json` (клавиши), `Saves/<main|justine>`. Графика, громкость, гамма и флаг первого запуска — общие (PlayerPrefs), как main settings HPL2. Новый профиль начинает с умолчаний; первый созданный забирает прежние настройки, клавиши и сохранения `Документы/RTXMnesia/Saves`.
- Как в оригинале: первый титульный экран запуска открывает окно профилей; нет профилей — сразу ввод имени («Новый игрок» выделено, до 20 символов без `*/\:<>|"?`, пробелы по краям обрезаются, пустое или существующее имя — «The profile name already exists»); список по дате создания, «Выбрать» / двойной клик, «Создать», «Удалить» с вопросом (удалённый используемый профиль снимается); закрыть без выбранного профиля — вопрос о выходе. Раскладка — menu.cfg `Profiles` (WindowSize, ListFontSize, EnterNameWindowSize, EnterNameButtonLength), крестик `WindowButtonCross`, поле `TextBoxBackground` / `TextBoxMarker`, верхний слой окна сообщения над окном имени.
- Отступления: запоминается последний профиль (`RTXMnesia.LastProfile`) — он выделен в окне (HPL2 выделял самый старый) и используется картой, запущенной в редакторе напрямую (HPL2 создавал `DefaultProfileName`); сохранения кампаний в разных папках.
- В batch-прогонах профиля нет (`HplProfiles.RootOverride` и `HplMenuScreen.RequireProfileInBatch` — для тестов).

**Сложный режим** — `ScriptApi/HplDifficulty.cs` (`cLuxBase::mbHardMode`, блоки «HARDMODE» кода игры). Выбор — окно `cLuxMainMenu_StartGame` (400 × 220: «Нормальный» / «Сложный режим», описание, «Начать игру» с вопросом `HardModeStartNewGame`) только в основной кампании (`AllowHardMode` есть лишь в main_init.cfg). Флаг пишется в сохранение и ставится при его загрузке (`BeginLoad`), переживает `HplGame.Reset`.
- Враги (`iLuxEnemyLoader`): дальность зрения и в темноте × 1.15, порог слуха × 0.6, FOV и FOVXMul × 1.1, поиск игрока (угол × 1.1, расстояния × 1.25, время × 2.5), патруль у игрока (угол × 1.25, расстояния × 1.5), ходьба × 1.1, бег × 1.2 (скорость, ускорение, торможение), поворот × 1.35, шаги в воде × 1.5; урон атак × 2. Нет музыки опасности. Шаги бегущего игрока для врагов громче × 2 и дальше × 1.25.
- Карта при каждой загрузке файла (`cLuxMap::LoadFromFile`): удаляется каждое 0.7–0.95-е огниво (больше огнив у игрока из 6 — реже) и каждый 0.65-й флакон масла по порядку сущностей; огнива игрока — перенесённые с прошлой карты.
- Игрок: рассудок 0 — смерть (`SetSanity`, `AddSanity`, `LowerSanity`), свет в темноте — радиус × 0.5, яркость × 0.75, проявление × 2.5; бочка с маслом — всегда 10; переход 27 → 28 — рассудок +100.
- Сохранения: автосохранений нет; в меню паузы «Сохранить» вместо «Сохранить и выйти» — за 4 огнива (`glHardMode_SaveCost`), над меню стоимость и число огнив, неактивно при нехватке и после сохранения в этом меню; файл `HardMode_…sav`. Смерть: подсказка `HardModeDeath` (кроме `DeathGrunt_22_Chancel`), после возрождения загружается новейшее сохранение, только `HardMode` (`AutoLoadFile`), иначе — главное меню.
- Отступление (как исправленные опечатки ключей): русские `HardModeSaveCost` / `HardModeSavePopup` / `HardModeTinderboxInInvenory` в base_russian.lang лежат в отдельной категории — читаются оттуда (HPL2 показывал английский); `HardModeStartNewGame` по-русски нет — свой текст. Ачивки не переносятся.
- Проверка: `RTXMnesia.EditorDev.HardModeTests.RunBatch` (`-batchmode -nographics -quit`) — 36 условий: удаление огнив и масла на `01_old_archives` по формуле, автосохранение, сохранение за огниво и его имя, флаг в файле, AutoLoad только `HardMode`, меню паузы (кнопка, блокировка, списание огнив), смерть от рассудка и её подсказка, свет в темноте, бочка на `11_study`, множители и урон грунта и отсутствие музыки опасности на `10_daniels_room`.

**Флешбэки** — `PlayerFlashback` (порт `cLuxPlayerFlashback`) и `HplArea` с типом Flashback: проверка пересечения с телом игрока раз в 0.1 с, отключение области, отложенные вспышки, сепия / радиальное размытие, громкость мира (запись 1), множители движения из `game.cfg`, голоса с субтитрами и коллбэк; очередь ждёт 6 с после окончания. `GetFlashbackIsActive` возвращает состояние помощника; во время флешбэка темнота не снижает рассудок. `FlashbackConverter` переносит все `source/flashbacks/*.flash` в игнорируемый `Resources/HplFlashbacks.asset` (`HplFlashbackAssets`), обновляя ассет на месте, и вызывается импортом уровня. Меню Import > Flashbacks (.flash), batch: `-batchmode -nographics -quit -executeMethod RTXMnesia.Importer.FlashbackConverter.ConvertBatch`; переимпорт карт не нужен. Проверка: `PlayerSimulation.RunBatch` на `02_entrance_hall`, вход в AreaFlashBack (Unity ≈ −33.25, 0, 9.75), `watch` / `sounds` / `shot`; регрессии `MapChangePreview.RunBatch` и `MainMenuPreview.RunBatch` (без -quit/-nographics). Флешбэк и вспышка эмоции сбрасывают врагов (`Reset` → ожидание). Процент завершения и журнал прогресса ещё не подключены.
