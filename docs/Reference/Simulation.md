# Прогон PlayerSimulation

> Вынесено из CLAUDE.md (2026-10-25) без изменений текста; перекрёстные ссылки «см. «Раздел»» ищи по заголовкам в `docs/Reference/`. Индекс — в CLAUDE.md.

**Прогон** — `PlayerSimulation`: на уровне с `HplMap` шаги идут через карту, сообщения `[Script…]` копируются в лог.
- Флаги:
  - `-scriptDebug` — области вступления активны сразу, вступление пропускается;
  - `-noScript`;
  - `-globals "имя=значение;…"` — глобальные переменные до старта карты (возвращение на хаб, например `key_study_1=key_study_1` — событие стража на `02_entrance_hall`);
  - `-seed N` — повторяемые `RandFloat`.
- Команды:
  - `watch t интервал` — шаги со строкой состояния скрипта: игрок, FOV/aspect/крен, затемнение/след/сепия, реплика, сообщения, таймеры;
  - `fx sepia|trail|fade|blur|flash|off значение`;
  - `goto x y z yaw`;
  - `start Зона`;
  - `interact`, `release`, `throw`, `scroll n`, `rotate on|off`, `mouse x y t [log]` (единицы мыши HPL за шаг, y вниз), `mouseuntil x y Переменная значение [t]` — так же, пока локальная переменная карты не примет значение (не дольше t с, по умолчанию 10; иначе предупреждение);
  - `aim Сущность [Тело]` — повернуть камеру на тело; `body Сущность` — состояние пропа/двери/лампы, тела, джоинты;
  - `call Функция аргументы` — вызвать функцию скрипта уровня.
  - `particles` — системы частиц: число частиц по эмиттерам, состояние, расстояние.
  - `sanity [значение]` — задать рассудок и вывести освещённость, темноту, удар / утечку / покачивание / обморок, эффект безумия и три главных источника света у игрока; `lightsoff` — скрыть весь свет сцены (проверка темноты, лучше с `-noScript`); `active Сущность true|false` — включить сущность (карты без порта скрипта); `fitsup dy` — помещается ли тело выше и что ему мешает; `health` — здоровье, ранение, брызги / вспышка, состояние смерти и чекпоинт (урон — `call GivePlayerDamage 60 claws true false`); `enemy [Имя]` — враги: состояние, чувства, путь, анимация, страх и музыка врагов (строка `watch` тоже показывает активных врагов); `insanity [Имя|random|stop]` — запустить / остановить событие безумия и вывести состояние обработчика; `ropes` — верёвки (длина, частицы, мотор, концы) и что держат липкие зоны.
  - `sounds` — играющие записи (имя, тип, расстояние, время), звуковые сущности, музыка, глобальные громкость и скорость.
  - `overlaps Сущность` — пересечения коллайдеров её тел между собой и с миром (глубина, направление, слой).
  - `hide lights|passes|volumes|<часть имени шейдера>` — выключить весь свет, custom pass, Volume или рендереры с таким шейдером (бисекция проблем рендера).
  - `walkto Имя [падение_м]` — пешком (поиск по сетке + настоящий контроллер игрока, двери открываются перед проходом, лёгкие ящики сдвигаются) к сущности или области; `pull Рычаг` — дойти до рычага и потянуть мышью, пока не сменится состояние; флаг `-noEnemyAI` отключает ИИ врагов. Автоматический обход карты: `RTXMnesia.EditorDev.JustineWalkthrough.RunBatch -amnesiaMap maps/ptest/01_cells.map [-walk doors|all|none] [-walkfrom Старт -walkdrop 25] [-open "moveobject,…"]` → `Logs/Justine_Walk_<карта>.txt` (журнал: `docs/ScriptPort/justine/walkthrough.md`).
  - Настоящие действия (2026-10-29): `pull Рычаг [состояние]`, `climb Лестница [up|down]`, `pick Предмет`, `use Предмет Цель` (из инвентаря), `carry Проп Цель` (в руках), `wheel Колесо направление секунды` (круги мышью), `door ДверьУровня` (настоящая дверь и штатный `HplMapChange` в следующую карту, прогон продолжается там), `credits`. Флаг `-scriptFile путь` — сценарий из файла (команда на строку, `#` — комментарий). Сквозной маршрут Justine: `-amnesiaMap maps/ptest/01_cells.map -noEnemyAI -scriptFile tools/Justine-Walkthrough.sim`.
- Строка состояния включает состояние игрока, прицел и текст фокуса.
- Пример: вступление `00_rainy_hall` — `-seed 1 -script "watch 80 2; shot awake"` (~70 с до первого квеста).
