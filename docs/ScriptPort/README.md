# Журнал переноса скриптов уровней (.hps → C#)

Для каждого уровня — отдельный файл `chXX/<имя_карты>.md`, например `ch01/00_rainy_hall.md`.
Цель: при баге быстро найти, какая функция оригинала соответствует нашему коду и где мы отступили от оригинала.

Оригиналы скриптов — контент Frictional Games, лежат в `source/maps/main/chXX/*.hps` (вне git).
Поэтому здесь **не копируем код оригинала**, а ссылаемся на него: `файл:строка` + имя функции.
Сравнивать «оригинал ↔ порт» удобно, открыв оба файла рядом.

## Шаблон файла уровня

```markdown
# 00_rainy_hall

Оригинал: `source/maps/main/ch01/00_rainy_hall.hps`
Порт: `UnityProj/UMnesiaRTX/Assets/Scripts/Levels/Ch01/RainyHall.cs`
Статус: не начат | в работе | готов | проверен в игре

## Функции

| `OnStart` (:120) | `RainyHall.OnStart` | готов | |
| `TimerIntroSequence` (:40) | `RainyHall.TimerIntroSequence` | готов | состояния 0–12 перенесены 1:1 |
```

## Вызовы API движка

Общие функции (`AddTimer`, `PlayMusic`, `SetPlayerActive`, `FadeIn`, …) реализуются один раз
в `Assets/Scripts/ScriptApi/`. Их перечень и статус — в [api.md](api.md).
