## Подозреваемые

- RT-тени «Ультра» при множестве ламп с тенями (зал `00_rainy_hall` требовал до ~260 карт теней; слоты RT-теней);
- RTGI «Высокое», RT-отражения, RTAO — вклад каждого;
- переполнение видеопамяти (бюджет текстур, рельеф мешей, буферы RT) → вытеснение в системную память;
- CPU: сборка ускоряющей структуры (много рендереров, рельеф мешей, динамические объекты), кэш теней.

## Что сделать

1. В тестовом плеере (удалить после) встать по `save.sav` отчётов 21-20-26 и 21-22-27; замеры: время GPU по проходам

2. Каждый эффект выключить по очереди, таблица «эффект → мс».
3. Сравнить с местом 103 FPS (21-10-01).
4. Итог — отчёт с причинами и предложениями (без изменений кода), записать в `docs/Reference/RayTracing.md` или
   отдельный документ; решение об исправлениях — с пользователем.
